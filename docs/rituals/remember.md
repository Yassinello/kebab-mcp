# Remember

**Say:** “remember that I prefer short answers”, “note that the launch moved to March”, “don't forget…”.

**What it does:** restates what to keep as one self-contained sentence, then picks where it goes:

- **Profile** for a lasting fact about you (preferences, role, projects, people). It reads `my_context` first to avoid duplicates, then appends one bullet with `my_context_update`. It rewrites the profile only when you ask, and shows the new text first.
- **Note** for everything else (ideas, decisions, links): appended to an existing note on the topic, or to today's inbox note `Inbox/YYYY-MM-DD.md`.

It confirms in one line where it saved. Sensitive or ambiguous items are checked with you before saving.

**Needs:** the profile (built in). The vault is optional: without it, only facts about you can be kept.

**Template:** [`content/skill-templates/remember/SKILL.md`](../../content/skill-templates/remember/SKILL.md)
